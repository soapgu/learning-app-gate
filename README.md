# learning-app-gate

一个通过学习任务、访问时段和每日额度管理目标 Android 应用访问的本地守门工具。

首版面向 HONOR GT（AMG-AN00，Android 16 / MagicOS 10）上的豆包使用场景，采用 Kotlin、Jetpack Compose 和无障碍服务实现。项目不依赖 Root、Device Owner 或荣耀企业 MDM。

## 当前状态

M0 真机可行性原型已经完成，并在目标真机上通过完整功能验证。当前已经具备：

- 未授权从桌面、搜索、最近任务、深链接或守卫测试入口启动豆包时实时拦截。
- 从守卫临时授权 30 秒或 10 分钟并启动豆包。
- 只在豆包前台累计额度，切后台、锁屏和息屏时暂停，返回后继续。
- 豆包前台顶部显示实时剩余时间胶囊。
- 额度耗尽后撤销授权并退出豆包；视频、会话、列表等多层页面通过条件驱动的 BACK 精准补发逐层退出。
- 到期瞬间已切换到其他应用时跳过 BACK，避免误退当前应用。
- 服务关闭或进程重建后恢复为未授权，不保留 M0 内存授权。

M0 的实现范围、技术决策和验收结论参见 [ROADMAP.md](ROADMAP.md) 与 [M0 总体验收记录](docs/validation/M0.md)。后续里程碑将继续实现访问时段、每日累计额度和学习任务。
