# M0 真机可行性原型总体验收记录

## 验收结论

M0 于 2026-08-23 完成。目标 HONOR GT（AMG-AN00，Android 16 / MagicOS 10）真机功能验证通过，普通无障碍服务能够完成豆包“未授权拦截、临时授权、前台计时、暂停恢复、实时收回”的完整闭环，可以进入后续里程碑。

## 实现结论

- `rootInActiveWindow` 在 `canRetrieveWindowContent=true` 后作为正常路径的前台包名依据；null 只按罕见窗口过渡态处理，并最多复检一次。
- 到期回调只有在活跃窗口明确属于豆包时发送 BACK；未知或其他应用均跳过。
- BACK 拦截采用一次主 BACK 加最多两次条件驱动精准补发。补发必须满足豆包 class 变化、活跃窗口安全检查和 400ms 最小间隔。
- 早于安全间隔到达的真实 class 变化不会被丢弃：系统保留原始页面基线，延迟复检后再决定是否补发。
- M0 授权与额度只保存在内存中，进程重建后恢复为未授权；每日额度持久化仍属于 M2。

## 已知边界

- 当前没有可复现的豆包通知入口样本，因此通知入口继续保留为已知测试缺口；包名级目标识别逻辑与其他入口共用。
- M0 不持久化授权或累计额度，也不提供访问时段、每日额度和学习任务；这些能力分别在后续里程碑实现。
