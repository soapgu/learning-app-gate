# M0 真机可行性原型

## 状态

**已完成（2026-08-23）。** M0.1～M0.8 已实现，并在 HONOR GT（AMG-AN00，Android 16 / MagicOS 10）完成真机功能验证。

## 目标

验证普通侧载 Android 应用在不使用 Root、Device Owner 或荣耀企业 MDM 的前提下，能否通过无障碍服务完成豆包的“未授权拦截、临时授权、前台计时、暂停恢复和实时收回”闭环。

## 用户流程

```text
未授权进入豆包 → 实时拦截并逐层退出
守卫创建临时授权 → 启动豆包 → 前台计时并显示剩余时间
切后台或锁屏 → 暂停计时 → 返回豆包后继续
额度耗尽 → 撤销授权 → 逐层退出豆包
再次进入豆包 → 继续按未授权拦截
```

## 核心行为

- 以包名 `com.larus.nova` 识别豆包，不依赖固定 Activity；桌面、搜索、最近任务和深链接入口共用同一判定。
- 未授权进入时发送一次主 BACK；豆包内部页面发生真实 class 变化时最多精准补发两次，逐层退出视频、会话和列表页面。
- 精准补发使用 400ms 最小间隔。class 变化过早时保留原页面基线并延迟复检，避免真实导航信号被防抖提前消费。
- 活跃窗口采用“目标、其他、未知”三态判定。`rootInActiveWindow` 为 null 时只复检一次；到期回调仅在前台明确为豆包时发送 BACK。
- 荣耀桌面、系统管理器和输入法等后台窗口噪音不会暂停计时或提前结束拦截会话。
- Debug 构建提供 30 秒和 10 分钟临时授权。豆包前台显示不可触摸的剩余时间胶囊，切后台、锁屏、到期或撤销授权时立即隐藏。
- 服务销毁时取消计时和覆盖层并撤销内存授权；进程或服务重建后默认恢复为未授权。

## 接口与架构

- `TargetApp` 集中保存目标包名、显示名称和启动能力，`TargetAppLauncher` 动态解析官方启动 Intent。
- `LaunchAuthorizationState` 包含 `Idle`、`Pending`、`Active`、`Paused` 和 `Revoked`；`Pending` 只允许由守卫的授权入口创建。
- `LaunchAuthorizationStateMachine` 负责纯状态转换，`PrototypeAccessController` 负责单调时钟计时和到期调度。
- `GateAccessibilityService` 负责窗口事件、前台仲裁、BACK 拦截和覆盖层生命周期，不计算授权额度。
- `GateInterceptionStateMachine` 控制拦截会话、防重入、补发间隔与补发配额。
- `BackRefillRecheckCoordinator` 保留延迟补发的原始 class 基线，并协调最新页面信号、消费和取消复检。

## 分阶段实施

1. M0.1 确认目标包名、入口和动态启动能力。
2. M0.2 验证 MagicOS 无障碍窗口事件与非目标分类。
3. M0.3/M0.3-plus 完成未授权拦截，并由 HOME 演进为条件驱动的 BACK 精准补发。
4. M0.4 引入临时授权和官方豆包启动链路。
5. M0.5 实现前台计时、到期收回和剩余时间反馈。
6. M0.6 实现切后台、锁屏和解锁后的暂停恢复。
7. M0.7 完成到期竞态、服务销毁、重连和目标崩溃处理。
8. M0.8 完成目标 HONOR GT 的 MagicOS 真机可靠性验证。

## 自动化测试

- JVM 单元测试覆盖授权状态转换、Pending 超时、Active/Paused 计时、到期幂等和调度恢复。
- 覆盖三态前台判定、拦截防重入、精准补发间隔、补发配额和延迟复检协调。
- 覆盖剩余时间格式、覆盖层显示策略、目标包匹配和启动授权状态。
- M0 收口时 `testDebugUnitTest`、`lintDebug`、`assembleDebug` 和 `git diff --check` 均通过。

## 真机验收

- 未授权从可复现入口进入豆包时能够退出，每个会话只产生一次拦截和提示。
- 30 秒和 10 分钟授权可以正常激活、前台计时并在到期后收回。
- 切后台、锁屏和息屏期间不消耗额度，返回豆包后继续计时。
- 到期瞬间切换到其他应用时不误发 BACK；豆包多层页面到期后可以完整退出。
- 覆盖层不闪烁、不抢焦点、不接收触摸，服务关闭或进程销毁后无残留窗口和任务。

## 范围边界

- 当前没有可复现的豆包通知入口样本，通知入口继续作为已知测试缺口。
- M0 授权和额度只保存在内存中，不提供每日累计额度或进程重启恢复；持久化属于 M2。
- 普通无障碍方案不能隐藏、停止或卸载豆包；用户主动关闭无障碍、卸载守卫或进入安全模式仍可能绕过保护。
- M0 只以目标 HONOR GT 为验收设备，不承诺其他品牌和系统版本兼容。
